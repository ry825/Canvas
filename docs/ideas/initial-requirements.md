# 初期要求仕様

## プロダクトの基本アイデア

Excelのように細かな単位で内容を扱いつつ、無限キャンバス上へ文章、表、画像、図形、コネクタを自由に配置して技術・業務文書を作成できるブラウザアプリを提供する。編集時の自由度と、完成した文書を読みやすいレスポンシブHTMLとして配布できることを両立する。

## 解決したい課題

- 一般的な文書エディタでは、文章と図解を自由に組み合わせたレイアウトを作りにくい。
- ホワイトボードや作図ツールでは、完成物を章・節のある読みやすい文書として配布しにくい。
- Web制作ツールはHTMLの知識を求めることがあり、技術・業務文書の作成には過剰である。
- 自由配置の見た目をそのままHTML化すると、スマートフォンで読みにくくなりやすい。

## ターゲットユーザー

- 手順書、設計概要、調査報告、業務フローなどを個人で作成する技術者・業務担当者
- テキストだけでなく、画像、表、図形、関係線を使って説明したい人
- HTMLやCSSを直接記述せず、ブラウザで閲覧できる成果物を作りたい人
- 初期版ではローカル環境で個人利用し、ファイルとして保存・共有する人

## 主要機能

- 章・節を管理する文書ツリー
- 節ごとの無限キャンバス編集
- 見出し、リッチテキスト、画像、表、図形、コネクタ、リンクの配置
- 要素の移動、リサイズ、整列、複数選択、複製、コピー＆ペースト
- Undo/Redo
- HTML出力用のブロック順とレイアウト指定
- JSON形式でのローカル保存・読み込み
- ブラウザ内の自動保存と復元
- 単一HTMLファイルおよびHTML＋アセット一式のエクスポート

## MVPの範囲

### 含める

- ローカル個人利用のブラウザアプリ
- 文書の新規作成、編集、保存、読み込み、自動保存
- 章・節ツリーと基本的なキャンバス編集
- 基本要素7種類
- レスポンシブHTMLへのエクスポート
- CSS・画像埋め込み型の単一HTMLと、ZIP形式のフォルダ出力

### 含めない

- ログイン、クラウド同期、共同編集
- PDF出力
- 文書テンプレート
- Excelファイルの取り込み、表計算数式、高度なセル結合
- AIによる文章生成やレイアウト生成
- プラグイン機構
